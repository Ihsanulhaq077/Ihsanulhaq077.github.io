## 🎨 Customization Guide

### Update Personal Information
Edit `index.html` to modify:
- Name and title
- About section content
- Project descriptions
- Skills and technologies
- Contact information
- Social media links

### Customize Colors
Edit `:root` variables in `style.css`:
```css
:root {
  --bg: #0b0f1a;              /* Background */
  --primary: #6c63ff;         /* Primary color */
  --accent: #00d4ff;          /* Accent color */
  --text: #e6e9f0;            /* Text color */
}
```

### Adjust Animations
Modify timing and effects in `script.js`:
- Typing speed: Line 21 & 25 (70ms and 40ms)
- Counter animation: Line 44 (40ms step)
- Scroll reveal threshold: Line 63 (0.12)
